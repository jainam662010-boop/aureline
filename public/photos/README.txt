Lifestyle photos
================

The homepage "Worn in the wild" section looks for these files:

  lifestyle-01.jpg   model in Vintage Washed Oversized (black)
  lifestyle-02.jpg   model in French Terry Hoodie (olive)
  lifestyle-03.jpg   model in Heavyweight Box Tee (white)
  lifestyle-04.jpg   model carrying Raw Canvas Merch Tote

Guidelines
- Portrait crop, 4:5 (e.g. 1600 x 2000 px), sRGB JPEG/WebP.
- Keep the print clearly visible; the tile crops from the centre.
- Under ~400 KB each keeps the homepage fast.

Until a file exists the tile renders a clipped garment mockup with the
matching customer artwork and a small "Photo slot" badge, so nothing breaks.
